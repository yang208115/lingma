# 助手历史对话管理

## 用户流程

- 写作助手与大纲助手共用「历史对话」入口。历史页占用侧栏内容区，返回后保留聊天与未发送的输入，不再挤在聊天顶部的两个下拉框里。
- 对话按最近活动时间排列，并按今天、昨天、日期分组；列表显示标题、最近消息摘要、消息数、生成次数及当前对话标记。
- 搜索在服务端查询当前作品所有对话的标题和消息内容，支持分页，不局限于已经加载的列表。
- 点击对话恢复消息和最新一次生成，可接着发送消息；每份对话的「生成记录」显示该对话自己的任务、时间、状态及回复摘要，可打开修改建议和重试入口。历史生成在消息已加载的范围内保留原有顺序并定位，不把所选回复一律挪到对话末尾。
- 支持就地重命名，删除时移入回收站，可恢复。删除仅标记会话，不删除小说正文、版本、消息、运行、修改候选或已经接受的章纲。
- 活动任务结束前限制切换和管理，生成过程仍继续接收事件。服务器拒绝删除有未结束任务的对话，已删除对话不能继续用于新任务或重试。
- 读取历史失败时显示错误与重试，分页失败保留已加载数据；切换会话、搜索或退出页面后丢弃过期的查询结果。加载更早消息时保留当前阅读位置。
- 「刷新模型列表」移入写作设置，历史页的刷新只刷新历史。

## 数据与接口

- 新增 `0015-session-history.sql`，追加会话 `updated_at`、`deleted_at`，回填已有会话活动时间，并在运行创建和结束时更新活动时间；补充历史查询索引。后端重新载入时应用迁移。
- `GET /projects/:id/sessions` 增加 `q`、`deleted=0|1`，返回列表摘要和分页游标。
- `GET /sessions/:id` 返回活动会话信息；`PATCH /sessions/:id` 修改标题；`DELETE /sessions/:id` 移入回收站；`POST /sessions/:id/restore` 恢复。
- 生成摘要增加 `taskPreview`，列表和聊天展示时隐藏大纲规划的内部任务前缀；完整任务和运行快照保留用于回放。
