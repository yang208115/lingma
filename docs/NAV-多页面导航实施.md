# 多页面导航实施

2026-11-04：主要模块由工作台内切换及主弹窗迁移为独立路由页面，继续使用 Vite、React、现有 Node 服务及数据库。

## 页面入口

| 页面 | 地址 |
| --- | --- |
| 作品管理 | `/projects` |
| 写作 | `/projects/:projectId/writing?document=:documentId` |
| 大纲 | `/projects/:projectId/outline?document=:documentId` |
| 基本信息 | `/projects/:projectId/information` |
| 通用 Skill | `/skills` |
| 项目 Skill | `/projects/:projectId/skills` |
| Agent 角色库 | `/agents` |
| 工作流模板 | `/workflow-templates` |
| 模型设置 | `/settings/models` |
| Agent 提示词 | `/settings/agent-prompt` |

左侧分为作品管理、当前作品、创作工具与设置四组，当前作品组提供选择器。桌面可收起侧栏，窄屏用抽屉导航，支持 Escape 关闭及焦点约束。当前页面高亮并更新浏览器标题。写作区仅展示正文和 AI 助手，章节切换收进编辑器工具栏；新建、导入、卷章管理和导出位于“文档操作”菜单。总纲、章纲及其目录在独立大纲页面管理。助手宽度拖动按实际两栏宽度计算。此调整按用户要求未运行测试或构建。

角色与模板为全局配置。角色试运行通过页面内的作品与章节选择器定位，选项使用 `project`、`document` 查询参数保留；协作写作统一在对应作品的写作助手内运行。新建、重命名、删除确认、导入预览和版本历史等操作继续使用弹窗。

新建长篇先进入基本信息引导，完成后进入大纲。短篇直接写作；短篇不显示基本信息入口，访问其基本信息地址会转到写作并显示原因。

## 路由和状态

- 使用锁定的 `react-router@7.18.5`、`createBrowserRouter` 与嵌套路由。页面按需加载，地址决定页面、当前作品、选中文档与协作运行。普通导航新增浏览器历史，默认文档补全及地址转换替换当前记录。
- 应用级 `DraftStore` 管理跨页面串行保存；共享作品上下文加载目录、处理错误与重试，并在返回后刷新其他页面修改过的干净文档缓存。含未保存修改的文档不被服务器快照覆盖。
- 离开正文或大纲页面前完成待保存请求。失败或版本冲突时保留当前地址与草稿，通过原有保存、重试和合并入口解决；前进后退遵循同样规则。章内切换继续使用原有草稿队列。
- Skill、角色、模板、模型配置与系统提示词的未保存修改通过统一离开提示处理，可留在原页或放弃后离开。基本信息离开前提示尚未保存，沿用其浏览器恢复草稿。刷新和关闭继续使用浏览器离开保护。
- AI 未发送输入、模型选择、当前会话及运行标识按作品保存在本标签页。页面卸载清理 SSE 订阅，不取消服务端生成；返回读取服务端快照并重新订阅，不自动重发请求。后台任务不自动采纳正文。
- 独立协作写作页面已移除，运行卡片内展开完整记录。旧工作流地址跳转到写作页；`run` 参数转换为 `workflow` 定位对应运行，并恢复其所属会话；无会话的历史运行同样可打开。校验运行属于当前作品，接受最终正文后同步编辑器最新版本。

浏览器恢复数据使用 sessionStorage，仅供本标签页恢复；存储不可用时沿用相关功能的既有提示，不能代替服务端保存和备份。模型密钥不写入这些恢复项。

## 兼容和错误处理

`/` 默认转到作品管理；旧 `/?project=…&document=…&view=…` 地址转换为新路由并保留定位。未知路径显示未找到页面，作品加载失败提供重试与返回入口，已删除作品按不可用处理。文档和协作运行都校验作品归属，不展示其他作品的正文或运行结果。

服务端沿用 HTML 导航回退，支持深层地址刷新；不存在的 API 和静态资源返回 404，缺失的 `/assets/` 资源不会回退为 HTML。没有新增后端 API，也没有修改数据库 schema 或迁移。
