# P05 写作流程实施

日期：2026-11-03。P05-01—09 已实现；真实供应商因环境无配置列为未验证。下一阶段 P06 尚未执行。所有自动化验证使用临时实例、合成资料及模拟供应商，不产生付费模型调用。

## 使用流程

1. 在顶部“模型设置”保存模型 ID、协议、接口地址、上下文及输出上限。API 密钥可直接填写并保存。服务端使用 AES-256-GCM 加密保存到 DATA_DIR/credentials.enc，本机加密密钥为 credentials.key，均限制文件权限；SQLite 和运行快照只保存 local:引用。已有 env:变量名配置仍兼容，接口不回显密钥。远程地址须为 HTTPS，本机 HTTP 支持无密钥模型。
2. “检查连接”是显式模型调用，只请求 OK、最多 16 个输出 Token、单轮、15 秒调用超时；可能产生供应商费用。页面展示实际模型、检查 ID、结果和已知用量。配置校验成功或环境变量存在不代表已接通供应商。
3. 在正文旁选择模型及任务用途并填写任务。服务端自动把已导入 Skill 的名称、description 和版本标识加入系统提示词；Agent 判断适用性后用 `load_skill` 读取完整入口，用 `read_skill_file` 按需读取附件，可加载多个 Skill，也可在没有 Skill 时直接完成任务。写作界面无需选择 Skill 或版本。续写以整章为目标；选中改写使用已保存版本的 UTF-16 选区和原文 hash。审校/聊天默认只读，可单独授权当前目标的修改提议。
4. “保存草稿并预览上下文”先保存当前作品的待保存编辑，冲突/失败时停止。可排除允许读取的资料、固定全文、允许未来章纲，再次预览。超限也保留清单供调整。未来正文不能提前读取；未来章纲必须授权，并始终标为规划；明确选为当前审校目标的章纲始终可读，其提议权限仍须额外授权。
5. 开始执行后可查看轮次、实际输入、动作与结果、实际引用、Token/费用及停止原因。关闭页面、断网不取消任务；需要停止时使用“取消运行”。
6. 助手回复（包括流式输出和历史消息）按 Markdown 显示标题、列表、加粗、引用与代码。工具提议完整轮次提交后，自动在中间正文编辑区打开目标文档与修改对比：正文使用正常字色与阅读排版，新增用绿色细线和加号标记，删除用红色细线、减号与删除线标记；选区改写保留全文，只替换对应选区后比较，空原文显示全部新增，无改动会明确提示。原文读取失败可重试。右侧保留“在正文区查看差异”入口及可展开的完整草稿 Markdown 预览。正文顶部固定工具栏提供“采纳修改”（写入并保存版本）、“返回编辑”和“拒绝”，正文区域只保留简短范围说明与差异；返回编辑后同一提议的后台刷新不会重新打开对比。当前草稿或版本已变更时提示重新生成并禁用写入，服务端仍会检查版本冲突。完整最终候选也能显式创建提议并显示差异。确认写入后新增 `source=proposal` 的文档版本，之后可在原版本历史中比较和恢复。

若当前文档已经变化，接受返回 409，提议标为 stale，候选和作者新稿均保留。相同提议重复或并发接受只返回原 acceptedVersionId，不重复创建版本。

普通写作与修改审阅共用居中的阅读栏。正文输入区随内容和栏宽自动伸展，取消内部滚动条与手动拖拽角；正文页统一滚动，选区与自动保存机制沿用原实现。固定工具栏显示保存状态、保存、历史，删除与章节导出收进“文档操作”菜单；文档信息折叠在正文末尾。此次界面调整按用户要求未运行测试。

正文右键菜单提供撤销、重做、剪切、复制、粘贴、全选和“发送到 AI 对话框”，展示对应平台的快捷键，无选区时禁用剪切、复制和 AI 引用，粘贴保留可用。剪切先成功复制再删除，粘贴按打开菜单时的选区替换或插入；等待剪贴板权限期间若取消菜单、正文改变或组件卸载，不再写入原文。编辑命令沿用浏览器撤销历史，浏览器不允许剪贴板操作时提示使用快捷键。AI 引用附上当前文档标题，将选中文字按 Markdown 引用追加到右侧尚未发送的提问，保留原输入并将焦点移到末尾，由作者继续填写和手动发送。相同选区可重复插入；输入合计超过 32000 字符时提示缩小选区，不截断或覆盖原输入。处理中暂存插入请求，处理结束后填入。菜单支持方向键导航、Escape、点击外部和滚动关闭，并在视窗边缘调整位置；按住 Shift 右键时保留浏览器默认菜单。未运行测试。

“在正文区查看差异”会等待基准正文加载和差异渲染完成后，定位到第一处新增或删除，并留出顶部固定工具栏的空间；重复点击同一提议也会重新定位，不再强制回到章节标题。无变化时定位到对比说明。未运行测试。

鼠标右键打开菜单时保留正文输入框的焦点及选区，点击菜单项时阻止鼠标按下转移焦点，避免选中文字的高亮消失。菜单键或 Shift+F10 打开时使用键盘焦点导航；鼠标菜单打开后也可按方向键进入菜单，Escape 返回正文。未运行测试。

## 实现与数据

共享契约为 `packages/shared/src/writing.ts`，动作的正文/元数据引用契约位于 `actions.ts`。`apps/server/src/writing/` 分为供应商配置、上下文、限定动作、SQLite 记录器、存储与管理器；`http/writing.ts` 提供 API，前端由 `WritingPanel`、`ProviderManager` 和 `writing-api.ts` 接入。

迁移 `0004-writing.sql`、`0005-writing-citations.sql` 将 schemaVersion 从 3 升到 5，保留 P01—P03 的资料与 Skill 数据，增加：

| 表                                 | 用途                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------- |
| provider_configs / provider_checks | 非敏感配置、乐观修订号及实际连接检查记录                                |
| sessions / messages                | 作品/章节会话、用户任务和完整提交的助手消息                             |
| runs                               | 输入、完整上下文/非敏感配置快照、检查点、用量、候选、状态和事件游标     |
| run_documents                      | 固定 documentId/versionId、只读或目标提议权限                           |
| run_context_entries                | 初始实际片段及通过校验的工具读取结果，含元数据、hash、范围和 citationId |
| run_turns / tool_executions        | 各轮实际 request/response、partial_text、完整检查点及动作参数/结果      |
| proposals                          | staged/pending/accepted/rejected/stale/abandoned 与接受版本             |
| run_events / idempotency_keys      | 可重放事件与同事务提交的幂等响应                                        |

已应用的 0004 保持原 checksum，0005 以复制保留记录、替换表约束的前向迁移允许同一引用按不同轮次记录，旧开发实例也可正常升级。迁移回归验证旧引用及外键保留、同轮去重、跨轮重复允许。

设计稿中的配置/输出字段在当前实现合并进 `snapshot_json`、`output_json`，并非额外的 config_json/output_message_id 列。初始引用 turn_index=-1，动作引用按实际轮次保存。模型提供的 citationId 必须已实际输入或成功返回；被长度限制拒绝的工具结果不会登记为可引用资料。

## API

Agent 提示词可在顶部独立编辑器中修改，保存到 `0006-agent-prompt.sql` 新增的 agent_prompt_settings 单行配置表，当前 schemaVersion=6。默认值来自 shared/agent-prompt.ts，未自定义时 revision=0；保存带 revision，冲突返回 409 并保留界面编辑。文本最多 32000 字符，不接受空白或 NUL，保留原始换行。恢复默认先修改编辑内容，需保存后生效。配置影响所有作品的新任务，初始 systemPrompt 由配置正文加自动 Skill 目录组成；快照保存 agentPromptRevision 并计入上下文 hash，创建事务再次校验修订号。既有运行与检查点重试使用原快照，不受后续编辑影响。

模型配置的上下文窗口与输出上限均接受正的安全整数，不按应用预设 262144/32768 上限；前后端保持一致，500000 的上下文窗口可直接保存。仍要求输出上限小于上下文窗口，显式 maxTokens 不超过配置输出上限。实际模型能力由用户按供应商配置，运行仍保留请求大小与工具结果等资源限制。

前缀均为 `/api/v1`，返回统一 `{data}` 或 `{data,nextCursor}`；输入、输出和前端事件均按 shared schema 校验。

| 方法与路径                                                                 | 行为                                                          |
| -------------------------------------------------------------------------- | ------------------------------------------------------------- |
| GET / PUT `/agent-prompt`                                                  | 读取当前及默认提示词；按 prompt/revision 保存全局设置         |
| GET / POST `/provider-configs`；GET / PUT / DELETE `/provider-configs/:id` | 查询/新增/按 revision 修改或删除，最多 50 个配置              |
| POST `/provider-configs/:id/check`；GET `/provider-configs/:id/checks`     | 实际检查、最近 50 条结果；运行队列非空时拒绝检查              |
| POST `/context/preview`                                                    | 校验归属、资料版本和目标，返回完整实际输入及 hash，不创建运行 |
| GET / POST `/projects/:id/sessions`                                        | 分页会话列表、创建作品或章节会话                              |
| GET `/sessions/:id/messages`                                               | 从最近消息向前分页；每页内部按时间正序展示                    |
| GET / POST `/runs`                                                         | 按作品/会话分页、创建后台运行，创建返回 202                   |
| GET `/runs/:id`                                                            | 一致快照：状态、事件水位、轮次、动作、上下文、提议和用量      |
| POST `/runs/:id/cancel`；POST `/runs/:id/retry`                            | 显式取消；终态重试创建新运行，返回 202                        |
| GET `/runs/:id/events?after=0`                                             | 持久化 SSE；`check=1` 可在建立流之前探测游标                  |
| POST `/runs/:id/proposals`                                                 | 用已提交最终 messageId 创建候选提议，不接受客户端任意替换文本 |
| GET `/proposals/:id`；POST `.../accept` / `.../reject`                     | 查询、原子接受或拒绝                                          |

创建运行、重试、创建候选提议及接受提议要求 `Idempotency-Key`。同 scope/key/request 返回首次响应；内容不同返回 409。会话、消息与运行列表默认 50、上限 200，返回 nextCursor；前端支持继续加载。provider 列表及连接检查记录有明确固定上限。

模型设置选择已有配置后可点击“删除配置”，确认后删除配置及其连接检查记录，并重置为新建表单。DELETE 请求体必须携带当前 revision；修订冲突、相关运行未结束、可继续的工作流仍引用该配置或连接检查进行中时返回 409。历史写作记录、运行快照和本机凭据保留，以支持历史运行的显式重试；角色中已绑定的配置需要重新选择。

运行输入使用 `writingRunInputSchema`：在 P01 createRun 基础上限制任务 32000 字符、固定版本 200 个，增加可选 allowedVersionIds、审校目标提议授权及 expectedContextHash。skillVersionId 为可选字段，仅供明确指定版本或实验；普通写作不发送。预览快照的 skills 保存当时所有可用 Skill 的名称、描述和不可变版本，工具只接受此清单中的版本。UI 始终带预览 hash；变更资料、Skill 或配置后 hash 不一致会拒绝创建。显式固定旧版本仍读取该不可变版本。同一文档一次只允许一个版本，目标始终加入允许清单。

## 上下文和资源限制

中文采用词片段匹配（最多 64 个），结合人物姓名/别名、当前章纲和相邻两章排序，不使用只适合英文空格分词的检索。人物元数据随片段输入和动作结果返回。Skill 初始输入只包含目录摘要；缺少 description 时明确标记，Agent 可按名称加载了解。load_skill 返回完整 SKILL.md、manifest 路径及缺失关联文件诊断，read_skill_file 只读取清单内版本的 UTF-8 文本附件，不执行脚本，二进制读取返回错误。所有结果作为 toolResult 加回同一循环，后续调用据此继续；记录和检查点保留完整内容，重试复用原目录和已提交加载结果。会话输入采用最近 20 条成功运行消息，完整聊天记录另可分页查看。

2026-11-04：写作助手顶部新增文字按钮“清空上下文”。点击后解除当前会话与运行的选择，清空聊天显示、上下文预览、资料固定/排除选择及幂等请求缓存；保留尚未发送的输入、模型和任务用途。下次发送新建独立会话，不携带旧会话消息；历史会话与运行仍可查阅。正文与作品设定继续按写作设置读取。正在生成或处理操作时禁用按钮；旧会话异步响应在切换后不能重新填回聊天区。本次仅做前端构建、格式与页面检查，未跑测试套件。

目前没有可靠 tokenizer。按实际请求 JSON 的 UTF-8 字节数作保守 Token 估计，预算为 `floor(contextWindow × 0.85) - reservedOutputTokens`，包含应用规则、Skill、历史、资料清单、工具定义及元数据。每轮工具结果加入对话后再次检查；超限停止并保留上一完整检查点，不继续调用。此估计可能提前拒绝，不能作为精确计费或供应商兼容性保证。

作者固定全文不静默裁剪；选中改写默认输入选区及两侧各 1000 字符，显式固定时输入全文。推荐片段最多 2000 字符，超预算会列出省略原因。允许读取上限 1000 份/正文与元数据合计 800 万字符；超限要求缩小允许清单。Skill 入口沿用导入时的 256 KiB 上限；实际初始请求 300 万字符，写作 API 请求体 4 MiB。正文和 Skill 附件每次最多 8000 字符；附件结果包含 from/to/totalChars/truncated 供继续读取。检索最多 20 个结果、每条最多 1600 字符。循环和动作注册器不再额外限制序列化结果长度；所有追加内容仍受每轮上下文预算限制。

管理器实例全局同时执行 1 个运行，活跃队列上限 32。同一作品只能有一个活跃 write/rewrite，同一会话只允许一个活跃运行；SQL 部分唯一索引也约束占用。冻结依赖在活跃期间不能删除，编辑仍可新增版本。默认 8 轮/每轮 8 动作/每次 120 秒/总期限 10 分钟。其他保护沿用 P04。

Token 与费用未知均为 null；已知部分显示已知值并标记不完整，按币种汇总，不将 SDK 缺省零视为免费。UI 不设置金额硬预算。价格配置与远端实际计费可能不同，已经发出的请求不能撤销费用。

## 事件、取消与恢复

文本/动作参数按 50ms 或约 4096 JSON 字符合批。批次与 partial_text、last_event_seq 在同一短事务提交；保留合并后的最后 seq，序号可有间隔但严格递增。完整轮次原子写检查点、激活 staged 提议并提交轮次完成事件；终态原子写状态与 run.finished，作废未完成轮次提议。取消已持久化时，稍后到达的完成不能覆盖取消。

SSE 只读取已落库事件，每批最多 32 个，空闲轮询 200ms、心跳 15 秒；单次写等待上限 5 秒，慢连接关闭后仍可重放。运行线程不等待任何 SSE 消费者。浏览器先读快照，再订阅 after=快照水位，按 seq 去重。有效 Last-Event-ID 优先于 URL 中旧 after；非法游标返回 400，过期返回 410，前端重新取快照再订阅。普通断线由原生 EventSource 重连。

事件目前不自动清理；内部 expireEvents 只允许清理终态事件，推进 eventFloor，保留快照，P07 再接清理策略。没有“保存 N 天”的保证或外部清理接口。

启动将遗留 queued/running/cancelling 标为 interrupted，保留已提交片段、完整轮次和实际用量；不会自动调用供应商。重试新建关联 run，冻结原配置/版本，仅复用完整检查点及其有效引用，不重放已完成动作；新运行的用量另计。原运行状态保留。已有完整最终响应的终态不再重试，避免重复最终候选；需新任务时重新预览。优雅关闭先停止领取、关闭 SSE、取消模型及检查请求，等待短事务收束，再关闭数据库。
