# 实施基线与契约

整理日期：2026-11-10。本文记录当前工程采用的约定；需求来源仍保留在[需求确认表](./PRD-需求确认表.md)和 [PRD](./PRD-AI小说写作工作台.md)，实施选择不等于用户补填或确认了空白答案。

具体字段以 `packages/shared/src/` 的 Zod schema 为准，HTTP 行为以 `apps/server/src/http/` 为准。文档导航见[索引](./README.md)。

## 架构与依赖

| 包 | 职责与边界 |
| --- | --- |
| `packages/shared` | 领域类型、API 与事件 schema；只依赖 Zod，不依赖 Node、HTTP、React、SQLite 或 pi-ai |
| `packages/agent` | 自研 Agent 循环、Fake/pi-ai 适配、动作与记录器接口；通过注入访问资料，不直接接触数据库 |
| `apps/server` | Hono 路由、业务服务、SQLite 与附件；提供运行队列、上下文预览、提议与 SSE |
| `apps/web` | React/Vite 界面与流程画布；只依赖 shared，不引用 server/agent |

pnpm workspace、TypeScript、ESM 与固定版本依赖沿用既有技术决策。包边界由 `scripts/check-boundaries.mjs` 校验，浏览器产物由 `scripts/check-browser-build.mjs` 校验。shared/agent 改动后需重建其 dist，开发模式自动监听。

## 数据归属与保存

- 作品、文档、不可变版本、Skill 清单、角色、模板、运行、检查点、提议、对话和事件保存在实例 SQLite 中；附件按 SHA-256 放在 `DATA_DIR/blobs`。
- 当前每人独立实例，仅支持 loopback 监听。实例访问者共享数据，尚无账号隔离、跨设备同步或浏览器权威离线库。
- 浏览器 sessionStorage 保存本标签页草稿、输入及会话/运行定位。它不能替代服务端保存，关闭标签页可能丢失未保存内容。
- 文档保存检查 `baseVersionId`，冲突保留本地稿供比较与合并。历史版本不可变，恢复旧稿也新增版本；目录名称和排序由独立结构版本控制。
- 模型密钥以 AES-256-GCM 加密保存在实例目录，业务配置和快照只保留凭据引用，API 不回显密钥；兼容环境变量引用。
- 附件先写临时文件并 flush，再原子发布到 hash 地址，不覆盖既有文件；读取校验 hash，失败不创建数据库引用。孤立 blob 暂不自动回收。

数据目录使用进程独占锁，心跳更新间隔 10 秒、过期约 30 秒。不能多个进程共用目录或将 SQLite 放在网络文件系统上，也不能删除活跃实例锁。维护先阻止新写入并等待在途事务，关闭时收束运行、关闭数据库并释放锁。

数据库迁移只能新增，不能改写已应用 SQL 或 checksum；遇到未知新版本拒绝启动。项目已包含迁移 `0020-workflow-reset.sql`，各模块文档中的早期 schemaVersion 只表示该迁移引入时的版本。配置、迁移历史及清理备份的具体内容见[运行与数据维护](./运行与数据维护.md)。清理命令生成的恢复备份包含密钥，与尚未交付的可分发备份格式不同。

## 普通写作与 Agent 循环

1. 作者保存草稿，选择模型、用途、目标及允许资料，服务端预览上下文并冻结版本、模型配置、提示词和工具授权。
2. 系统提示词自动提供可用 Skill 的名称、描述与版本目录；Agent 通过 `load_skill` 和 `read_skill_file` 按需读取，Skill 文字不能扩大权限，脚本不执行。
3. 每轮模型完整响应到齐后才执行工具，按顺序校验参数、授权范围、引用与基准；流式片段仅供展示。
4. 提议先暂存，随完整轮次与检查点一同提交。中断轮次的暂存提议作废；模型结束与候选是否被接受分别记录。
5. 作者接受时在事务内重新检查目标与基准，新增正式版本。重复接受返回同一应用结果，基准变化返回冲突。
6. 手动重试创建新 run，保留原记录并复用最近完整检查点。服务重启将遗留任务标记中断，不自动重发模型请求。

当前写作流程已移除固定轮数、每轮工具数、模型请求超时、任务期限与累计 Token 硬限额，也不再执行旧的应用超时自动重试。模型正常结束、作者取消或实际错误时停止；上下文容量、输出配置和各业务对象的大小校验仍生效。具体沿革见 [P05 持续执行策略](./P05-写作流程实施.md#持续执行策略2026-11-04)。

实际上下文用请求 JSON 的 UTF-8 字节保守估算，留出余量并预留输出；固定资料超限要求作者调整，不静默省略。未知 Token/费用保持未知，不同币种分别累计，不提供金额硬预算。

模型调用结构为 `{id, name, arguments}`，结果以 `callId` 对应，并携带成功值或公开业务错误。固定动作注册表校验参数与结果；内部异常不暴露敏感细节。普通写作、新章创建、总纲与章纲候选的权限和互斥规则见[写作流程](./P05-写作流程实施.md)及[大纲实施](./OUTLINE-大纲实施.md)。

## 编排契约

角色与模板保存草稿、乐观锁 revision 和不可变发布版本。运行冻结角色、模板、模型、提示词、Skill 与资料，修改配置不影响已有流程。

编排节点直接以最终 Markdown 回复为产物，仅有读取类工具；作者闸门、产物编辑、依赖失效、逐条采纳、修订与最终保存由确定性编排器控制。普通审校流程与自由 Agent 图分别处理审校修订和有限轮次反馈。

所有子运行与角色试运行共用全局模型队列：并发 1，活跃队列最多 32。同作品占用由父工作流与普通写作共同校验；等待作者、暂停和可恢复失败仍可持有占用。最终结果始终需要作者采用。

重启恢复先对账已完成子运行，再从完整检查点继续；远端计费状态可能未知，不承诺远端恰好一次。普通审校流程刷新资料保留冻结执行配置，自由图及内嵌辩论需新建运行获取最新资料。详见[通用编排实施](./MA-通用编排与流程画布实施.md)和[自由图与辩论](./自由Agent图与多轮辩论.md)。

## HTTP、事件与幂等

ID 使用 UUID，时间使用 UTC ISO 8601，hash 为 64 位小写 SHA-256。服务端负责作品归属、类型、允许资料和版本权限校验，不信任模型或浏览器传入的越权目标。

普通 run SSE 的事件类型放在 `event`，`id` 为持久化事件 seq 的十进制字符串；seq 从 1 起、可有间隔，turnIndex 从 0 起。有效 `Last-Event-ID` 优先于 `after`，非法游标返回 400、已清理游标返回 410，前端先补读快照再订阅。工作流父事件使用 `change`，文本、思考和工具详情沿用子 run API。

创建运行、重试、提议、接受及编排相关操作按接口要求提供 `Idempotency-Key`：8—128 个 ASCII 字母、数字、下划线或连字符。服务端对通过 schema 的请求规范化计算 SHA-256，键顺序排序、数组顺序保留。

同 scope/key/hash 返回首次结果；同 scope/key 不同 hash 返回 409 `IDEMPOTENCY_CONFLICT`。业务写入与幂等结果同事务提交，失败回滚不占用键。即使换键，重复接受同一提议也返回原版本。草稿、结构和作者决策额外通过版本号或 `expectedRevision` 检查竞态。
