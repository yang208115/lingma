# 运行与数据维护

## 启动与服务边界

安装与启动命令见[项目 README](../README.md#本机运行)。开发模式由 Vite 提供前端并将 `/api` 代理到后端；构建模式由 Node 同时提供页面与 API。

健康探针为 `/api/v1/health`、`/api/v1/ready`，也提供 `/health`、`/ready`。就绪返回 200，维护或关闭时 ready 返回 503；迁移失败直接退出，不开放端口。

当前仅允许 loopback Host 与监听地址。公开部署所需的认证与 HTTPS 尚未交付，当前服务端口不适合通过反向代理公开。

## 配置与数据

`.env` 始终从仓库根目录加载，环境已提供的变量优先。相对路径也以仓库根目录解析，不受启动时工作目录影响。Vite 只读取 HOST/PORT 用于代理，不把 `.env` 注入客户端。

| 变量                | 默认值        | 说明                             |
| ------------------- | ------------- | -------------------------------- |
| HOST                | 127.0.0.1     | 仅允许 127.0.0.1、localhost、::1 |
| PORT                | 3000          | 1—65535                          |
| DATA_DIR            | .data         | 实例私有目录，不能与静态目录重叠 |
| TEMP_DIR            | DATA_DIR/tmp  | 导入暂存；可配置独立私有目录     |
| WEB_DIST_DIR        | apps/web/dist | 构建后的前端目录                 |
| SHUTDOWN_TIMEOUT_MS | 10000         | 优雅关闭期限，100—60000ms        |

```text
.data/
  .instance.lock/          # 进程独占心跳锁
  workbench.sqlite        # 作品/资料/Skill/运行/提议/事件及迁移记录
  workbench.sqlite-wal    # SQLite 运行时文件，不能忽略它直接复制主库做备份
  workbench.sqlite-shm
  blobs/ab/<sha256>       # 不可变附件
  tmp/
  backups/                # 仅建立目录，完整实例备份工具尚未交付
```

数据目录仅由一个进程使用，不支持网络共享文件系统。重复启动会被拒绝；正常退出释放锁，异常退出的锁最多等待约 30 秒过期。不删除活跃实例的锁。数据库、真实环境文件及附件目录均由 `.gitignore` 排除。

迁移位于 `apps/server/src/db/migrations/`，当前 schemaVersion=20；P05 的 `0004-writing.sql` 增加运行、配置、会话、提议与事件，`0005-writing-citations.sql` 扩展逐轮引用唯一约束，`0006-agent-prompt.sql` 保存全局 Agent 提示词，`0007-run-thinking.sql` 保存逐轮思考内容并恢复旧记录已保存的可显示文本，`0008-workflows.sql` 和 `0009-agent-trial-versions.sql` 增加角色、模板、工作流及未发布角色试运行，`0018-workflow-session-history.sql` 为通用编排会话历史增加索引，`0019-skill-scopes.sql` 区分通用与项目 Skill，`0020-workflow-reset.sql` 随编排重设计清空旧模板与运行记录（保留角色库、模型配置与全部文档）；保留已有作品及 Skill 历史，并保持已应用迁移的 checksum 不变。启动自动校验迁移版本及 checksum，应用未执行迁移；修改已执行迁移或使用未知新版本数据库会拒绝启动。升级发布、回退及完整实例备份工具尚待实现，当前不提供数据库降级。

## 清理数据并保留模型信息

```sh
pnpm data:clean                 # 只预览表记录数和待移除目录
# 先停止 pnpm dev / pnpm start，再执行：
pnpm data:clean --execute
```

保留模型设置（`provider_configs`）、加密 API 密钥（`credentials.enc` / `credentials.key`）、数据库结构与迁移记录，`.env` 保持原样。清空其余业务表，包括作品、正文和历史、聊天、运行记录、Skill、Agent 角色、工作流、全局提示词及模型连接检查历史，同时删除附件、旧备份和导入临时文件。自定义 `TEMP_DIR` 仅清理 `novel-imports` 和 `skill-git-*`，其余文件保留；浏览器本地草稿和界面偏好不属于服务端清理范围。

执行时使用与服务相同的实例锁，拒绝清理正在运行的数据目录。删除前在数据目录旁创建 `<数据目录名>.backup-*`，保存 SQLite 一致性快照、数据目录内其他文件及外置导入暂存。备份失败时不删除原数据。备份包含清理前的数据与密钥，请妥善保管；确认无需恢复后可自行移除。恢复时停止服务，以备份内容替换数据目录；如使用外置暂存，将备份中的 `__external_temp__` 内容还原到 `TEMP_DIR`。脚本读取根目录 `.env`，也支持环境变量覆盖 `DATA_DIR` / `TEMP_DIR`。
