- `apps/web/src/style.css` 集中管理全站样式。后续按页面或功能拆分，核对共享变量与类名引用。
- 服务端 `workflows/service.ts`、`elements/service.ts` 仍承担较多职责。编排已拆出图、提示词、上下文、结果和保存适配器，调度、闸门与恢复仍可继续拆分。
- 逐个检查异常捕获是否保留足够诊断信息，重点关注 HTTP 与数据库边界；文件存在性探测和断开连接处理等预期异常应区别处理。

原问题清单中的 SSE 慢客户端超时逻辑已提取到 `apps/server/src/http/sse.ts`，写作、要素与编排路由共用。旧版 schemaVersion、未提交文件数量和已失效的文档链接问题不再保留为待办。

## 产品范围与验证缺口

- Skill 案例管理与双版本效果比较（原 P06）尚未交付。
- 服务器公开发布所需的认证、TLS、交付镜像和完整实例备份/恢复方案（原 P07）尚未交付。当前仅支持本机监听，每人独立实例。
- 浏览器草稿恢复不等于离线数据库；账号隔离、多人共用和跨设备同步需要单独设计。
- 可靠 tokenizer 与金额硬预算尚未提供；当前有上下文容量检查和用量记录，未知费用保持未知。
- 真实供应商的文学质量、延迟与费用未由本地模拟测试证明，需使用实际模型另行评估。
- 编排的独立整页节点产物界面仍是设计目标，当前通过运行卡与编辑区预览查看。整书连续写作、跨作品输入、条件脚本与任意外部工具不在当前交付范围。
