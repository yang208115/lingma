## 维护约定

- 功能变化更新对应实施文档；配置与数据操作统一写入运行维护文档，README 保留入门入口。
- 需求与设计记录保留原始确认信息，并明确区分设计目标和当前实现。
- 被替代的方案在有效内容合并后删除，并同步修复引用。待办使用可核实的问题描述，不记录容易失效的文件行数或未提交文件数量。
- `fixtures/` 中的 Markdown 和 TXT 是测试输入，清理文档时保留。
